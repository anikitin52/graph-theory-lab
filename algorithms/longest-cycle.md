# Алгоритм: наибольший простой цикл по DFS-дереву

**Вход:** простой неориентированный граф `G = (V, E)`, списки смежности `Adj[v]`.  
**Выход:** список вершин цикла наибольшей длины вида «ветвь DFS-дерева + обратное ребро»
или пустой список, если граф ацикличен.

## Идея
- Относительно DFS-дерева все не древесные рёбра — **обратные** (соединяют потомка с предком), поперечных рёбер нет.
- Обратное ребро `(u, w)`, где `w` — предок `u`, вместе с путём `w → u` по дереву даёт простой цикл длины `d[u] − d[w] + 1`.
- Для каждой ветви (путь «корень → лист») выбираем обратное ребро, дающее самый длинный цикл,
  затем берём лучший цикл среди всех ветвей.

## Псевдокод

```text
procedure LONGEST_CYCLE(G):

    // Шаг 1. DFS-лес
    for v in V:
        color[v] ← WHITE; parent[v] ← NIL; d[v] ← 0
    for v in V:
        if color[v] = WHITE:
            d[v] ← 0
            DFS(v)

    // Шаг 2. Обратные рёбра
    B ← []
    for u in V:
        for w in Adj[u]:
            if w ≠ parent[u] and parent[w] ≠ u and d[w] < d[u]:
                B.append((u, w))

    // Шаг 3. Листья (концы ветвей)
    Leaves ← { v ∈ V : v не является parent ни для какой вершины }

    // Шаг 4. Лучший цикл по всем ветвям
    bestLen ← 0; bestU ← NIL; bestW ← NIL
    for ℓ in Leaves:
        P ← путь от корня до ℓ (по parent[])
        for u in P:
            for (u, w) in B:                 // обратные рёбра, выходящие из u
                len ← d[u] − d[w] + 1
                if len > bestLen:
                    bestLen ← len; bestU ← u; bestW ← w

    // Шаг 5. Восстановление цикла
    if bestLen = 0:
        return []                            // циклов нет
    C ← []; x ← bestU
    while x ≠ bestW:
        C.append(x); x ← parent[x]
    C.append(bestW)
    return C

procedure DFS(u):
    color[u] ← GRAY
    for w in Adj[u]:
        if color[w] = WHITE:
            parent[w] ← u
            d[w] ← d[u] + 1
            DFS(w)
    color[u] ← BLACK
```

## Сложность
- Шаги 1–2: `O(n + m)`.
- Шаг 4 в прямом виде: `O(n·h)`, где `h` — высота дерева; при однократном просмотре каждого обратного ребра — `O(n + m)`.

## Замечание
Задача о самом длинном простом цикле NP-трудна. Алгоритм даёт самый длинный цикл вида
«ветвь дерева + обратное ребро» для построенного DFS-дерева, то есть нижнюю оценку.
